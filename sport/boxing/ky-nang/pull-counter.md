# Pull counter

> **Tiếng Anh:** Pull Counter · [← Quay lại bách khoa](../TAT-CA-KY-NANG-BOXING.md#7-counter-punching) · ⭐⭐⭐ · Counter / pull back / Mayweather

---

## Phân tích tình huống

Pull counter: lean back né jab/cross, counter cross/hook ngay — Mayweather specialty. Timing chính xác — pull quá sớm miss, quá muộn ăn đòn. Lỗi: pull không counter, pull vs hook (nguy hiểm).

---

## Cách phòng thủ / hóa giải

Tránh pull counter: body shot trước — pull back hở bụng. Feint jab draw pull rồi hook thật. Double jab, cú thứ hai bắt khi họ đang recover pull. Hook sau jab thay vì cross — pull counter cross là signature. Không lean forward khi jab. Mix jab với step to side. Đọc khi họ hay lean back — setup trap.
