# Pull back

> **Tiếng Anh:** Pull Back · [← Quay lại bách khoa](../TAT-CA-KY-NANG-BOXING.md#5-phòng-thủ-defense) · ⭐⭐ · Defense / lean / counter

---

## Phân tích tình huống

Pull back là nghiêng thân về sau (lean back) để đòn đi qua — giữ chân, chỉ upper body lean. Floyd Mayweather signature. Hiệu quả vs jab và cross tầm xa. Lỗi: pull back quá xa (mất balance, khó counter), pull back khi đối thủ tầm gần (vẫn ăn hook), không counter sau pull back. Pull back + counter cross/hook. Cần core strength — tập plank và lean drill.

---

## Cách phòng thủ / hóa giải

Chống pull back: body shot (lean back hở body); feint draw lean rồi jab thật; step forward khi họ lean (cut distance); hook vòng (lean back không né hook ngang tốt).
